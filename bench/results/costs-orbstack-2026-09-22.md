# Cost probes on `orbstack`, 2026-09-22

Three serial runs, a few seconds apart, of the probes built with `zig build-exe bench/costs/main.zig
-target aarch64-linux-musl -O ReleaseSafe` and run in the Linux gate's container without a cpuset
(`bench/costs/README.md`, "orbstack"). The `orbstack` column of `docs/costs.md` holds run 1,
without C12 and C13, which that file excludes for this machine. The load average before each run is
the `mac` machine's, whose cores this virtual machine runs on.

The two-thread rows C15, C17 and C19 pinned both threads to cores 0 and 1, and C14 pinned its one
thread to core 0; the method lines say so. The rows before C14 are not pinned, and a virtual CPU may
be backed by an efficiency core of the host, which the probe cannot see or choose: C7, C8 and C9
moved by up to 25 percent between runs (C7 193, 238, 234 ns), and C15 by 46 percent (9,333, 8,896,
13,000 ns). C17 read 10,981, 10,750 and 11,263 ns.
