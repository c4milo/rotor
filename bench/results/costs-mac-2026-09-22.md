# Cost probes on `mac`, 2026-09-22

Three serial runs of `zig build bench-costs`, one minute apart, on mains power, with the desktop in
use (a terminal, this editor and a browser open; no batch job). The `mac` column of
`docs/costs.md` holds run 1. The load average (1, 5 and 15 minutes) before each run is from
`uptime`, on a machine with 10 cores.

The rows disagree between runs only where a thread is woken: C18 read 18,125, 25,291 and 25,250 ns,
and C14 read 12,791, 13,792 and 12,417 ns. Every other median agrees within 2 percent. macOS has no
hard affinity, so no row here pinned a thread; each method line says so.
