# Measured runs

One file per set of runs: the program's output as it was printed, inside a fenced block, with the
machine, the date, the command and the load average before each run. Nothing is edited or rounded.
`docs/costs.md` copies its cells from these files, and a decision record that reports a number
points at the file it came from.

A file is named `<what>-<machine>-<date>.md`. The machines are the rows of `docs/costs.md`.
